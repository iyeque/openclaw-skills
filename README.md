# Iyeque OpenClaw Skills

Focused, security-reviewed skills for practical OpenClaw workflows.

These skills are designed around explicit capabilities, bounded inputs, predictable JSON output, and clear data boundaries. Each skill is also published on [ClawHub](https://clawhub.ai/) under `@iyeque`.

## Security model

- Local file operations are bounded to their documented inputs and scopes.
- Audio local-processing actions do not need network access; remote Google TTS is explicitly opt-in.
- Web search sends queries to Tavily only with `--allow-network`; local workspace search requires `--allow-local`.
- Device control uses fixed actions, strict numeric validation, and an application allowlist; it does not execute arbitrary shell commands.
- System diagnostics are read-only; process usernames are excluded unless explicitly requested.
- PDF processing is local, read-only, and bounded to 500 pages by default.
- Generated bytecode, cached models, credentials, and personal data do not belong in this repository.

## Development

Validate every skill locally:

```bash
for dir in skills/*; do
  python3 /home/ubuntu/skills/skill-creator/scripts/quick_validate.py "$dir"
done
```

Keep the ClawHub package and repository contents aligned. Do not commit `.clawhub/`, `_meta.json`, `skill-card.md`, `__pycache__/`, `.pyc`, `.pyo`, or `.pyd` files.
